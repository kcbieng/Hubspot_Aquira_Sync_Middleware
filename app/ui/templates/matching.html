Company & contact matching rules

Sales creates leads in HubSpot before Aquira exists; these rules tell the sync how to recognise them when the real record arrives, instead of creating a duplicate. Rules run top to bottom and the first rule that matches decides the outcome — put the strongest, most specific rules first and use ▲ ▼ to reorder. Within one rule, every listed field pair must match. Auto-link binds the records (writes aquira_id); Suggest lists the pair in each sync run for a human, who confirms by setting the HubSpot record’s Aquira ID property. A record already linked to another Aquira entity is never re-matched, and one HubSpot record can take only one. If a rule list is empty the built-in domain/name heuristic applies.
